# Information Architecture — Gomoku

> hybrid 模式自動產出。Sitemap、導覽層級、角色可見矩陣。

## 1. Sitemap

```
首頁 (home)
├── 本地雙人 ──────────────► 棋盤對局 (game, local) ──► 結束畫面 (result) ──► 再戰/重置 ↺ 或 回首頁
│      └─(勾選 Swap2)──► 開局 (opening: 教學→放置→三選一) ──► game
│
├── 線上連線 (需身份)
│      ├── 未登入 ──► 登入/註冊/訪客 (user)
│      └── 已登入/訪客 ──► 大廳 (lobby)
│             ├── 建立房間 ──┐
│             ├── 加入房間碼 ─┤──► 房間 (room: Ready/聊天/觀戰席)
│             └── 快速配對 ───┘        └─ 雙方 Ready ──► 硬幣投擲 (opening)
│                                          ├─(普通)─► game
│                                          └─(Swap2)► 開局放置→三選一 ─► game ─► result ─► rematch/離開
│
├── 登入/註冊/訪客 (user)
│
└── (已登入 header) 戰績/排行榜 (leaderboard)
        └── 最近對戰紀錄 ──► 回放 (replay)
```

## 2. 導覽層級

| 層 | 元素 | 出現位置 |
|----|------|---------|
| L0 全域 Header | Logo（回首頁）、身份區（暱稱/登入/登出）、戰績入口（註冊） | home, lobby, leaderboard, replay |
| L1 模式入口 | 本地雙人 / 線上連線 | home |
| L2 對戰前 | 大廳操作（建房/加入/配對）、房間（Ready/聊天） | lobby, room |
| L3 對戰中 | 棋盤、回合/連線狀態、開局子流 | game, opening |
| L4 對戰後 | 結束橫幅、再戰、查看回放 | result |
| 覆蓋層 | 教學 Modal、硬幣動畫、Toast、結束覆蓋 | 全域元件 |

> 對戰中（game/opening）採「沉浸式」：隱藏全域 Header，僅保留最小返回/離開入口，避免誤觸離開對局。
