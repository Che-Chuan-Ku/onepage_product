# UX Foundation — Gomoku 五子棋

> hybrid 模式自動產出。從 activities / actors / ui 推導使用者、任務、風險、可用性目標。

## 1. Actors（角色）

| 角色 | 類型 | 核心動機 | 關鍵限制 |
|------|------|---------|---------|
| **訪客玩家 (GuestPlayer)** | Primary（降低門檻） | 立即開玩，不想註冊 | 線上僅單場、不存戰績、不可直接再戰、觀戰唯讀 |
| **註冊玩家 (RegisteredPlayer)** | Primary（核心留存） | 累積戰績、排行榜競爭、回放複盤 | 需登入持 JWT |
| **觀戰者 (Spectator)** | Secondary（對戰席滿衍生） | 旁觀學習 | 全唯讀：不落子、不 Ready、無再戰 |

> 觀戰者非獨立帳號類型，而是訪客/註冊玩家在「對戰席已滿」時加入房間的狀態（SpectatorJoinedRoom, Q5）。

## 2. Core Jobs（核心任務）

| Job | 對應 Activity | 頻率 | 風險 |
|-----|--------------|------|------|
| J1 快速開一局本地對戰 | 本地雙人對戰 | 高 | 低 |
| J2 線上配對/開房對戰 | 線上連線對戰 | 高 | 中（斷線、配對逾時） |
| J3 Swap2 開局決策 | 本地/線上對戰 | 中 | **高**（規則複雜、權限敏感、悔子） |
| J4 註冊/登入/訪客進入 | 使用者管理 | 中 | 中（錯誤處理 UX, #23） |
| J5 查戰績/排行榜/回放 | 使用者管理 | 低-中 | 低 |

## 3. 高頻任務（最佳化路徑）
- **落子**（game）：點擊/觸控交叉點。行動版需放大確認/精準輔助（#18），是全 app 互動密度最高處。
- **進入對戰**：首頁兩大按鈕，3 次點擊內可開局（本地）。

## 4. 高風險任務（重點防護）
- **Swap2 開局**：權限控制（非當前操作方禁用）、每子確認、悔最後一子、三選一說明 → 必須有清楚的「輪到誰」狀態與規則教學（#33 首次提示）。
- **線上落子驗證**：伺服器權威，前端非法落子須即時 Toast（InvalidMoveRejected），不可樂觀更新導致誤導。
- **斷線**：Loading/重連提示，雙方斷線逾寬限判和（#15 #23）。

## 5. 可用性目標（可量測）

| 目標 | 指標 |
|------|------|
| 易上手 | 首次使用者無教學可在 30 秒內開始一局本地對戰 |
| Swap2 可理解 | 首次 Swap2 玩家看完教學提示後能正確完成三選一（不誤點） |
| 觸控友好 | 行動版落子點擊區 ≥ 44×44px（含放大確認） |
| 錯誤可恢復 | 所有失敗操作有明確 Toast + 不破壞當前狀態 |
| 狀態透明 | 任何時刻玩家能看出「輪到誰、自己執什麼色、連線狀態」 |

## 6. 情緒/語氣
專注但不嚴肅的對弈氛圍。深色木質棋盤質感 + 沉穩配色，勝負時刻給予恰當的慶祝動效（連五高亮、結束橫幅）但不喧賓奪主。
