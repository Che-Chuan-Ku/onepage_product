# 模式選擇首頁（衍生補全）

> spec-reader 推導。補全 specs/ui/模式選擇首頁.md 未明確的 header 三態與入口顯隱。
> 不汙染 specs/，僅供 prototype 設計依據。

## Header / 身份三態

| 身份 | Header 右上 | 模式按鈕可用性 | 次要入口 |
|------|------------|---------------|---------|
| 未登入（無 guest） | 「註冊 / 登入」「以訪客遊玩」 | 本地雙人：可用；線上連線：點擊先提示登入或訪客 | — |
| 訪客（已輸入暱稱） | 暱稱 + 「升級為註冊」 | 兩者皆可用（線上限單場） | 提示「訪客線上戰績不保存」 |
| 註冊玩家（持 JWT） | 暱稱 + 頭像 + 「戰績 / 排行榜」「登出」 | 兩者皆可用 | 排行榜、回放入口 |

## 線上連線點擊未登入分支（需求 #2）
點「線上連線」且未登入 → 彈出選擇：
- A：前往登入 / 註冊（導 user 頁）
- B：輸入暱稱以訪客單場遊玩（導 user 頁訪客 tab）
- 關閉：留在首頁
