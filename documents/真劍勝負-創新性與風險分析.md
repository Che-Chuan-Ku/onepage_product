# 真劍勝負模式 — 創新性與潛在風險分析

> 分析對象：需求明細.csv 編號 34–48（真劍勝負模式，15 條）
> 規則依據：`documents/clarify/2026-07-04-1021.md` 定案紀錄
> 用途：開發前決策參考，非需求文件，不改動既有需求明細與 clarify 紀錄

## 執行摘要

真劍勝負模式在傳統五子棋「純位置、完全資訊、單調棋局（落子後永久存在）」的基礎上，疊加了隱藏陷阱格、可摧毀棋子的場地事件、以及職業技能造成的推擠與換色效果，這在五子棋類遊戲中相當罕見，最大膽的突破是打破「棋子一旦落下即永久存在」與「完全資訊」兩條五子棋的核心公理。風險集中在四處：先手優勢疊加技能可能被進一步放大、劍士大絕（天地反轉）換色機制的翻盤力可能壓過策略性、結算 pipeline 與推擠解算器的實作複雜度高、以及 15 條 Should 需求一次到位會讓依賴鏈（PushResolver → 技能 → 場地）互相卡住。建議以「劍士 + 火山場地」先驗證核心結算鏈路，弓箭手與沙灘場地（16×16 棋盤）留待第二批。

## 一、創新性分析

### 1.1 真正新穎的設計點

**隱藏陷阱格（噴發格、漲潮格）— 打破五子棋的「完全資訊」公理**

編號 39、40、44 引入 server-only、玩家事先不可知的隱藏格（火山噴發格 ≤5、沙灘漲潮格 ≤5）。傳統五子棋與市面常見變體（連珠、六子棋、Pente、Renju 禁手規則）全部維持完全資訊博弈——玩家永遠知道棋盤全貌，唯一的不確定性來自對手的選擇。真劍勝負模式讓棋盤本身帶有玩家不可見的觸發點，這在連線類（connection game）抽象策略遊戲裡幾乎沒有先例，較接近戰棋/roguelike 的「戰爭迷霧＋陷阱」設計語彙。編號 44 要求觀戰者也是同玩家視角看不到隱藏格，可見這是刻意的核心機制，而非附加彩蛋。

**可摧毀棋子的場地效果 — 打破「棋子落下即永久存在」的單調性**

編號 39 火山噴發燒毀周邊 8 格棋子（棋格仍可再下，只燒落子）、編號 41 海浪推子與漲潮侵蝕，都讓已落子的位置狀態可以被場地事件改變或清空。傳統五子棋的核心不變式是「棋局狀態單調遞增，落子只增不減」；這裡棋子會被燒毀、被推走、甚至整排沙灘變海洋後棋子「保留但變成海洋棋子」，等於引入了狀態可逆/可摧毀的機制。這個變動比職業技能更根本，因為它動搖了五子棋規則體系賴以判定勝負的最基本假設。

**連鎖推擠作為橫劈/縱劈/海浪三處共用的統一機制（編號 38）**

推擠玩法本身在其他棋類遊戲中存在（如 Quoridor 的阻擋、部分變體五子棋的「移子」規則），但真劍勝負模式把「連鎖推擠、末端出界移除、遇障礙物整列不動」設計成一個獨立共用元件，同時服務攻擊技能（橫劈/縱劈）與場地自然事件（海浪）。這是工程設計上的優點（單一元件、單元測試覆蓋一次到位），創新程度更多在「架構統一性」而非玩法本身。

**大絕換色（天地反轉）— 顏色互換式逆轉**

編號 42 的天地反轉可以把 3 寬 × 2 深共 6 格內的敵方棋子直接變成己方顏色。相較於推擠、消除、替換單子（弓箭手精準狙擊）等常見於棋類變體的操作，「一次性大範圍換色」更接近卡牌/派對遊戲（如部分翻轉類桌遊）的逆轉機制，而非傳統抽象策略遊戲手法。這是本批設計中翻轉力道最強、也最偏離五子棋「靠連線取勝」核心邏輯的一項。

### 1.2 既有機制的組合，非全新發明

- **職業與技能系統**：職業選擇＋固定技能組（劍士/弓箭手）＋每技能一場限用一次，是戰棋、卡牌對戰（如 Onitama、部分 CCG）常見的不對稱能力設計，移植到五子棋上是「組合」而非發明。
- **場地/環境機制**：障礙物格（開局隨機生成、雙方可見、禁止落子）屬於棋類變體常見手法（如部分五子棋變體會加入禁手格或障礙格）；本身不算新，新穎點在於障礙物之上疊加隱藏噴發格的雙層設計。
- **雙棋盤尺寸（15×15 一般/火山 vs 16×16 沙灘專用）**：棋盤尺寸依場地而異，是既有「地圖差異化」概念的延伸，玩法上不算突破，但技術上要求解耦棋盤常數（備註已明確指出「現有渲染器寫死 15×15 需參數化」），值得留意。
- **单一判定點結算（編號 37）**：先結算所有效果（落子→技能→場地）才判定勝負一次，這種「延遲判定」邏輯在需要處理連鎖效果的遊戲（卡牌對戰的疊加觸發）中常見，屬既有模式的合理套用。
- **同時五連時行動方勝**：多數對戰遊戲對「同時達成勝利條件」都採取行動方優先的裁決，屬慣例做法，非創新。

### 1.3 與傳統五子棋 / 常見變體的對照

| 面向 | 傳統五子棋 / 連珠規則 | 市面常見變體（Pente、Gomoku+障礙格等） | 真劍勝負模式（本批需求） |
|---|---|---|---|
| 資訊完整性 | 完全資訊，棋盤全貌雙方皆知 | 完全資訊 | 引入隱藏格（編號 39/40/44），棋盤帶有玩家不可見的觸發點 |
| 棋局狀態變化 | 單調遞增，落子只增不減 | 少數變體有「提子」（如 Pente 的夾吃），仍屬可預期規則 | 棋子可被場地事件摧毀（噴發燒毀、需求 39）或被動移動（推擠/侵蝕，需求 38/41） |
| 玩家能力 | 對稱，雙方規則完全相同 | 多數仍對稱；先手方常靠 Swap2 類機制平衡 | 不對稱，職業技能（需求 35/42/43）造成雙方能力差異，且與 Swap2 互斥、改用投硬幣決定先手 |
| 棋盤幾何 | 固定尺寸（多為 15×15） | 固定尺寸 | 依場地不同（15×15 火山 / 16×16 沙灘），且沙灘場地棋盤內部地形（海洋/沙灘比例）隨時間演變 |
| 勝負判定時機 | 每手落子後立即判定 | 每手落子後立即判定 | 延遲到本回合所有技能與場地效果結算完，才做唯一一次判定（需求 37） |

此對照顯示：真劍勝負模式偏離傳統五子棋最遠的兩個面向是「資訊完整性」與「棋局狀態單調性」——這兩者恰好也是後續風險分析中技術複雜度與使用者體驗風險最集中的來源，創新程度與風險程度呈正相關，並非偶然。

## 二、潛在風險分析

### (a) 遊戲平衡

| 風險 | 嚴重度 | 緩解建議 |
|---|---|---|
| 先手優勢 × 技能疊加：真劍勝負與 Swap2 互斥、先手仍用投硬幣決定（編號 34），沒有 Swap2 的均衡機制來抵銷先手優勢；先手方若同時搶到有利技能使用時機，優勢可能被進一步放大 | 高 | 上線後追蹤先手方勝率數據；若明顯失衡，考慮為真劍勝負模式設計獨立的先手補償規則（如限制先手方前 N 手不可用大絕） |
| 大絕換色（天地反轉）翻盤力：可在結算完才判定勝負的規則下，直接把即將連五的敵方棋子換成己方顏色，等同一擊逆轉，可能弱化前段布局策略的價值 | 高 | 進行數值 playtest，觀察「大絕決定勝負」的對局佔比；若過高，考慮追加使用限制（例如錨點格周邊需已有一定數量敵方棋子才可施放，目前僅有「一場一次」限制可能不足） |
| 職業不對稱：劍士（位置操控：推子）與弓箭手（直接替換/消除敵方棋子）強度特性不同，兩者在不同棋局階段的價值差異可能很大 | 中 | 分職業統計勝率，必要時微調技能參數（推格數、散射距離限制、大絕範圍） |
| 場地與職業聯動失衡：火山場（防守方受惠於障礙拖慢節奏）與沙灘場（持續侵蝕逼迫節奏加快）可能各自利好不同打法 | 中 | 分別統計兩場地下各職業勝率，視數據決定是否場地與職業需要聯動微調 |

### (b) 技術複雜度

| 風險 | 嚴重度 | 緩解建議 |
|---|---|---|
| 結算 pipeline（編號 37）：落子→技能效果→場地效果全部結算完才做唯一一次勝負判定，任何順序錯誤或狀態競態都會導致誤判（例如本應被燒毀的連五被誤判獲勝） | 高 | 抽出獨立 GameLogic 結算服務，針對技能×場地所有組合寫完整單元/整合測試 |
| 推擠解算器（編號 38）：連鎖推擠、出界移除、遇障礙物整列不動，橫劈/縱劈/海浪三處共用同一元件，任何 bug 會同時影響三種效果 | 高 | 獨立 PushResolver Service + 邊界情境矩陣測試（多重障礙、連續出界、多顆棋子連鎖） |
| 雙棋盤尺寸解耦：15×15（一般/火山）vs 16×16（沙灘專用），現有渲染器與後端棋盤常數目前寫死 15×15（備註已標明） | 中 | 在開發本批需求前，優先把棋盤尺寸重構為前後端共用參數，作為前置任務而非隨沙灘場地順便做 |
| 隱藏格防作弊（編號 44）：噴發格/漲潮格位置僅存 server 端、不下發前端，觀戰者也需同玩家視角過濾，增加 GameState DTO 層過濾複雜度 | 中 | 統一在 GameState 序列化層做隱藏格過濾，另寫模擬客戶端探測隱藏格的安全測試 |
| 斷線重連（編號 46）與回放擴充（編號 47）需要與新增的場地狀態（障礙、侵蝕進度、回合計數）、技能已用狀態深度整合，回歸風險高 | 中 | 優先為新狀態補齊重連與回放整合測試，避免既有重連機制因新欄位而隱性失效 |

### (c) 使用者體驗

| 風險 | 嚴重度 | 緩解建議 |
|---|---|---|
| 規則學習成本：新手需同時理解職業技能（4 種）＋雙場地機制＋隱藏格＋結算順序，複雜度遠高於原始五子棋規則 | 高 | 沿用編號 33 Swap2 教學提示的既有模式，為真劍勝負模式做首次進入教學（可跳過），並在結算動畫中清楚呈現因果（如編號 45 的特效） |
| 隨機性挫折感：隱藏噴發格/漲潮格玩家無法預知，連五被燒毀或棋子被侵蝕，可能造成「莫名其妙輸掉」的負面體驗 | 中 | 結算後清楚展示觸發原因與動畫，讓玩家理解「輸」的機制而非純運氣；首次教學明確提及隱藏機制的存在與機率 |
| 節奏與時長：沙灘場地持續侵蝕＋海浪機制讓後期棋盤佈局不斷被打亂，可能拉長對局或造成選擇癱瘓；技能/場地特效動畫（編號 45）過多可能拖慢對局節奏，尤其影響手機端體驗 | 中 | 控制動畫時長並提供可跳過設定；上線後收集實際對局時長，視需要調整海浪觸發頻率 |
| 16×16 棋盤在手機端的可讀性與觸控精度：既有 15×15 RWD 設計未必能直接套用到更大棋盤 | 低-中 | 沙灘場地上線前另外做一輪行動裝置 RWD 專項測試 |

### (d) 範圍蔓延

| 風險 | 嚴重度 | 緩解建議 |
|---|---|---|
| 15 條 Should 需求一次做完：技能系統、雙場地、隱藏格、結算 pipeline、重連、回放橫跨多個子系統，且彼此有依賴關係（PushResolver 需先於橫劈/縱劈/海浪；職業選擇需先於技能組），一次性交付任一環卡住會拖慢整批 | 高 | 依下方 MVP Slice 分批交付，先驗證核心結算鏈路可行後再擴充範圍，避免技術風險與平衡性風險同時爆發時難以定位問題根源 |

## 三、建議切分的最小可玩版本（MVP Slice）

**建議先做（第一批）：34、36、37、38、39、35、42、44、46**

- **34（房間建立與場地選擇）**：真劍勝負作為獨立房型的入口，沒有它整個模式無法啟動。
- **36（回合行動經濟狀態機）＋ 37（結算順序與單一勝負判定點）**：這是整個模式的規則骨幹，一般技能附掛落子 vs 大絕取代落子的行動經濟、以及「結算完才判定一次」的判定順序，必須最先落地且驗證正確，後續所有技能與場地效果都掛在這個骨幹上。
- **38（推擠解算器）**：橫劈、縱劈、海浪三個效果共用元件，技術風險最高、影響面最廣，應該最先獨立驗證（單元測試打滿），才能安全地讓其他效果依賴它。
- **39（火山場地）優先於 40/41（沙灘場地）**：火山場地維持既有 15×15 棋盤尺寸，不需要棋盤尺寸參數化這個獨立技術任務，能以最小改動驗證「隱藏格＋摧毀棋子」這個最新穎但風險也最高的機制；沙灘場地涉及 16×16 棋盤重構＋侵蝕狀態機，屬於獨立的技術挑戰，適合放到驗證完火山場流程穩定後再做。
- **35（職業選擇與鎖定）＋ 42（劍士技能組）優先於 43（弓箭手技能組）**：只先做一個職業，能把「職業選擇→技能觸發→推擠解算→結算判定」整條鏈路走通，且劍士的橫劈/縱劈屬於位置操控（重用 PushResolver），複雜度低於弓箭手的「替換敵方棋子顏色」「消除棋子」等更激進效果；等剑士這條鏈路穩定後，再加入弓箭手驗證與判定邏輯的交互（尤其是精準狙擊替換棋子後是否影響已排隊的勝負判定）。
- **44（隱藏格資訊管理）**：火山場地一旦上線就需要防作弊與觀戰視角過濾，不可省略。
- **46（斷線重連狀態恢復）**：線上模式核心保障，技能已用狀態與場地狀態（障礙物、已觸發噴發格）若不能隨重連恢復，會直接影響線上對戰可用性，不建議延後。

**建議延後（第二批）：43、40、41、45、47、48**

- **43（弓箭手技能組）**：等劍士驗證完整條結算鏈路後再加入第二套技能，避免一開始就要同時偵錯兩套技能與 PushResolver 的排列組合。
- **40、41（沙灘場地與海浪/漲潮）**：16×16 棋盤參數化與持續侵蝕地形是獨立的技術任務，且與火山場地機制正交，可等火山場地流程穩定、棋盤尺寸重構完成後再做。
- **45（技能與場地特效）**：純體驗層加分項，不阻斷核心規則驗證，可與 UI 設計階段並行甚至延後。
- **47（回放擴充）**：技能/場地事件的資料打點可以在第一批先做，但完整視覺重播可以延後，不影響對局本身。
- **48（本地雙人真劍勝負）**：需求已明確標示 Could、「第二波後補」，維持原定優先級即可，待線上模式驗證完整後再考慮。

### 3.1 分批依賴關係（為何是這個順序）

```
34 房間建立與場地選擇
   └─ 35 職業選擇與鎖定
        └─ 36 回合行動經濟狀態機
             └─ 37 結算順序與單一勝負判定點 ── 全模式的判定核心
                  ├─ 38 推擠解算器（共用元件）
                  │     ├─ 42 劍士技能組（橫劈/縱劈重用 38；大絕天地反轉獨立）  [第一批]
                  │     └─ 43 弓箭手技能組（散射/精準狙擊不依賴 38；獨立驗證） [第二批]
                  ├─ 39 火山場地（隱藏噴發格 + 44 隱藏格管理）        [第一批]
                  └─ 40/41 沙灘場地（16×16 棋盤參數化 + 海浪/漲潮）  [第二批，技術任務獨立]
   └─ 46 斷線重連狀態恢復（貫穿所有場地與技能狀態，第一批就要具備基本能力）
        └─ 47 回放擴充（依附於已產生的事件，可延後做完整視覺重播）
45 技能與場地特效（橫向貫穿，體驗層，可與 UI 設計並行）
48 本地雙人真劍勝負（Could，重用整套 GameLogic，放最後）
```
