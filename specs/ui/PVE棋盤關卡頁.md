# PVE 棋盤關卡頁

來源：PVE 增量 FR-B1~FR-B7、FR-C1~FR-C2、FR-C6（documents/PVE-挑戰模式-增量需求.md）

## 描述
PVE 關卡對局主畫面。單人挑戰 11×11 棋盤，以「連線造成傷害」擊破 Boss HP；無對手、純玩家單方落子。

## 佈局
- 棋盤（Canvas/SVG 繪製，11×11 固定尺寸，含星位）
- Boss HP 條：顯示目前/最大 HP（依關卡曲線，如 100/100、420/420 等）
- 手數預算列：剩餘手數 / 總手數預算（固定30）
- 關卡資訊：關卡序號（1/8）、場地類型（PLAIN/VOLCANO/BEACH）、Boss 突變標示（第3/6/8關：獨眼/震怒/深淵）
- 技能操作列：持有技能清單（含重複數量），點選後進入「獨立行動」使用模式；技能不佔用本手落子
- 場地視覺層：VOLCANO 可見障礙格圖示（3–5個）、BEACH 海洋/沙地分色渲染；隱藏噴發/漲潮格不顯示，
  觸發當下才播放特效並揭露
- 傷害數字浮動提示：每次連線結算時顯示造成的傷害與倍率breakdown
- 操作提示 / Toast 區（非法操作防呆、Loading）
- 「放棄挑戰」按鈕（含二次確認，視同失敗，FR-C7）

## 互動行為
- 點擊 / 觸控空白交叉點落子；非法位置（已佔/障礙格/超出11×11範圍）→ Toast 提示
- 落子後送後端結算連線傷害；一手最多4方向同時結算多條線，回應含 linesResolved 明細與扣減後 Boss HP
- Boss HP<=0 → 立即顯示「關卡通過」，不再允許落子；手數用盡且 Boss HP>0 → 顯示「關卡失敗」
- 點選技能按鈕 → 進入該技能專屬選取模式（方向/錨點/目標/第二子，同真劍勝負技能操作 UX），
  確認後獨立送出（不夾帶落子），成功後扣除持有數量並標示「本間隔已用技能」
  （每兩手之間至多用1個，FR-B5）
- VOLCANO 第6關「震怒」：每滿5手系統自動觸發噴發特效並更新受影響格；ABYSS 第8關「深淵」：
  每次連線結算後棋盤隨機新增一顆障礙棋子圖示
- BEACH 每10手觸發海浪特效並重繪受影響格；漲潮觸發後逐步顯示沙灘被侵蝕為海洋的漸進動畫
- 續玩：進入頁面時以 GET /pve/encounters/{encounterId} 取得快照渲染，接續最後一手（FR-B6）

## RWD
- 棋盤依視窗等比縮放，行動版觸控落子需有放大確認或精準點擊輔助
- 技能操作列於行動版收合為底部抽屜，避免遮擋棋盤
