# 對局回放頁

來源：需求 #17（遊戲歷史與回放）、#32（開局記錄與重播支援）、#47（真劍勝負回放擴充）

## 描述
重播一場已結束對局的完整落子序列（含 Swap2 開局子；真劍勝負對局另含技能與場地事件），供教學與 review。

## 佈局
- 棋盤（共用渲染，真劍勝負沙灘對局為 16×16）
- 回放控制列：上一步 / 下一步 / 播放 / 暫停 / 進度條
- 對局資訊：勝者、落子數、是否 Swap2；真劍勝負對局額外顯示場地類型、雙方職業

## 互動行為
- 載入指定 gameId 的落子序列 → 依 moveNumber 逐步重現
- 開局子（openingStones）在序列起始可被識別並重播
- 真劍勝負對局：技能事件（劈砍/狙擊/散射/大絕）與場地事件（噴發/海浪/漲潮/侵蝕）依 fieldEvents 的 moveNumber 與落子序列交錯重現，並附觸發特效播放（需求 #45 #47）
- 隱藏格（噴發格/漲潮格）在回放中可被完整揭露，不再受對局中的隱藏限制（需求 #44 #47）
