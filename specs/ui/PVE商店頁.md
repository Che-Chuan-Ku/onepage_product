# PVE 商店頁

來源：PVE 增量 FR-C3、FR-C4、FR-C5（documents/PVE-挑戰模式-增量需求.md）

## 描述
通過一關後進入的局間商店（第8關通關後不出現，直接進 Run 結算畫面）。固定展示遺物×2、技能×1，
供玩家花費金幣構築本輪 Run。

## 佈局
- 目前金幣顯示（本關通關獎勵 = 10 + 剩餘手數）
- 三個展示位卡片：預設遺物×2（含效果說明與售價）、技能×1（限自身職業3技能池抽取，售價固定6）——
  **A2 修正（2026-07-08 調校輪）**：當技能已達持有上限（3件）且遺物未達上限時，原技能展示位改抽
  第3件遺物（3 relic + 0 skill）；當遺物已達上限（5件）且技能未達上限時，兩個遺物展示位改抽技能
  （0 relic + 3 skill）；避免「該類別已達上限、商品仍佔位但永遠買不起」的廢卡體驗。僅在兩類同時
  達上限（此後全無可購商品）時維持舊行為（該槽維持原類別但停用購買按鈕）
- 已達持有上限（遺物5/技能3）時，對應商品卡片顯示「已達上限」並停用購買按鈕（僅適用於上述兩類
  同時達上限的僅存例外情形；一般情形下已達上限的類別根本不會再被抽出，見上）
- 「重抽」按鈕（固定5金幣，三位全部重新抽取，次數不限，僅受金幣限制）
- 「跳過」按鈕（不購買，直接進入下一關）
- 目前持有遺物/技能清單（供比對是否重複購買技能、確認遺物不重複）

## 互動行為
- 點「購買」→ 呼叫 POST /pve/runs/{runId}/shop/actions/purchase，成功後扣除金幣、更新持有清單，
  該展示位標示「已購買」
- 點「重抽」→ 呼叫 reroll，扣5金幣，三個展示位全部更新；金幣不足時停用按鈕並提示
- 點「跳過」→ 呼叫 skip，導向下一關（或第8關後導向 Run 結算畫面）
- 已持有的遺物不會出現在展示位中（FR-C4）
