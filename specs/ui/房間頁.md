# 房間頁（準備與聊天）

來源：需求 #7（房間內準備與聊天）、#26（Swap2 模式房間）、#35（職業選擇與鎖定）

## 描述
玩家進入房間後的等待頁。顯示雙方玩家、Ready 狀態、房間模式，並提供即時聊天。

## 佈局
- 房間碼（可複製分享）+ 房間模式標籤（普通 / Swap2 / 真劍勝負-場地圖示）
- 雙方對戰玩家槽位（暱稱 + Ready 狀態指示）
- 真劍勝負房間限定：職業選擇區塊（見 職業選擇介面.md），嵌於自己的玩家槽位下方
- 觀戰席列表（觀戰者暱稱清單 + 觀戰人數）；真劍勝負房間限定：觀戰者視角可見雙方（含選擇中未鎖定的）職業，不受「選擇階段對手不可見」限制（R2-2）
- 「Ready / 取消 Ready」按鈕（僅對戰玩家可見；觀戰者隱藏；真劍勝負房間限定：未選職業前按鈕停用）
- 即時聊天面板（訊息列表 + 輸入框）

## 互動行為
- 對戰席滿（2 人）後再加入者自動成為觀戰者，僅進觀戰席（SpectatorJoinedRoom）
- 切換 Ready → 即時更新雙方畫面（PlayerReadyToggled）；觀戰者無此操作
- 兩名對戰玩家皆 Ready → 自動進入開局流程（普通：硬幣決黑白；Swap2：硬幣決假先方；真劍勝負：硬幣決黑白後對局開始並揭曉職業）
- 真劍勝負房間：Ready 前可自由變更職業選擇；Ready 後鎖定；對手職業選擇過程對己方顯示「? 選擇中」（Q8 不可見）
- 聊天訊息即時廣播給房內成員（含觀戰者，WebSocket /topic/room/{id}）
