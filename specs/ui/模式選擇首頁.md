# 模式選擇首頁

來源：需求 #4（遊戲模式選擇首頁）、#18（RWD）

## 描述
進入應用的首頁。清楚以兩個大按鈕區分「本地雙人」與「線上連線」兩種模式。響應式設計，手機/平板/桌機皆流暢。

## 佈局
- 標題 / Logo 區
- 兩個並列大按鈕（行動版改為上下堆疊）：
  - 「本地雙人」→ 進入本地遊戲設定（可勾選啟用 Swap2）
  - 「線上連線」→ 進入大廳 / 房間
- 訪客 / 登入入口：未登入時提供「輸入暱稱以訪客遊玩」與「註冊 / 登入」

## 互動行為
- 點「本地雙人」→ 導向本地遊戲（含 Swap2 勾選，需求 #25）
- 點「線上連線」→ 若未登入，提示登入或以訪客單場遊玩（需求 #2）

## RWD
- Tailwind 媒體查詢；按鈕觸控友好，最小點擊區域符合行動裝置標準
