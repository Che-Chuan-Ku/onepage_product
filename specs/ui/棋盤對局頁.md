# 棋盤對局頁

來源：需求 #10（15×15 棋盤渲染與互動）、#9/#13（線上/本地落子）、#18（RWD）、#23（錯誤處理 UX）、
#39/#40（真劍勝負場地）、#42/#43（技能組）、#45（技能與場地特效）

## 描述
對局主畫面。繪製標準 15×15 五子棋盤（真劍勝負沙灘場地為 16×16），支援滑鼠與觸控落子，即時呈現雙方落子。

## 佈局
- 棋盤（Canvas/SVG 繪製，尺寸依場地參數化：一般/火山 15×15、沙灘 16×16），含星位
- 對局資訊列：雙方暱稱、當前回合指示、執黑/執白、落子數、計時
- 真劍勝負房間限定：
  - 對局開始時的職業揭曉橫幅（雙方職業卡片翻面動畫）
  - 技能操作列：己方職業對應的技能按鈕（一般技能 x2、大絕 x1），已使用技能標示為停用並打勾
  - 場地視覺層：火山障礙物圖示（雙方可見）、沙灘海洋/沙地分色渲染；隱藏的噴發格/漲潮格不顯示，觸發當下才播放對應特效並揭露該格
- 操作提示 / Toast 區（非法操作防呆、Loading）

## 互動行為
- 點擊 / 觸控空白交叉點落子；非當前回合或非法位置 → Toast 提示（InvalidMoveRejected）
- 線上模式：落子送後端驗證後廣播；本地模式：本地狀態機輪流落子
- 連線異常時顯示 Loading / 重連提示（需求 #15 #23）；雙方同時斷線逾寬限 → 判和局
- 觀戰視角：觀戰者僅即時同步棋盤與回合，棋盤不可點擊落子，並標示「觀戰中」與觀戰人數；真劍勝負對局中觀戰者同玩家視角，同樣看不到隱藏格（需求 #44）；惟雙方職業與技能操作列的已使用/未使用狀態，對觀戰者完全可見，不受「選擇階段對手不可見」限制（R2-2）
- 真劍勝負：點選一般技能按鈕後進入「附掛模式」，落子時一併送出技能參數（方向/第二子/目標）；點選大絕按鈕後進入「錨點+方向」選取模式，取代本回合落子，選取時即時顯示 3×2 範圍預覽框；技能結算後的推擠/燃燒/替換/清除/顏色互換觸發對應特效（具體動畫留待 UI 設計階段定案，需求 #45）
- 沙灘場地每 5 輪（10 手）觸發海浪特效並重繪受影響格；漲潮觸發後逐步顯示沙灘被侵蝕為海洋的漸進動畫

## RWD
- 棋盤依視窗等比縮放，行動版觸控落子需有放大確認或精準點擊輔助（觸控友好）
- 真劍勝負技能操作列於行動版收合為底部抽屜，避免遮擋棋盤
