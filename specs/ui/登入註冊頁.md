# 登入 / 註冊頁

來源：需求 #1（註冊·登入 JWT）、#2（訪客模式）、#23（錯誤處理 UX）

## 描述
帳號註冊與登入頁，並提供訪客暱稱入口。

## 佈局
- 切換頁籤：登入 / 註冊
- 登入：username + password
- 註冊：username + email + password
- 訪客入口：輸入暱稱 → 直接進入（單場線上 / 本地全功能）

## 互動行為
- 註冊成功 → 自動登入或導向登入；失敗（帳號/Email 重複、Email 格式錯）→ Toast 提示
- 登入成功 → 取得 JWT 並導向首頁
- 訪客暱稱為空 → Toast「請輸入暱稱」
