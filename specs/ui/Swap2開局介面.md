# Swap2 開局放置與選擇介面

來源：需求 #28（權限控制 + 每子確認 + 動畫）、#29（放置與選擇介面）、#31（悔最後一子）

## 描述
Swap2 開局階段的專屬介面。假先方逐子放置（每子確認 + 動畫），假後方在自己的選擇階段看到三個選項按鈕 + 簡短說明。

## 佈局
- 棋盤（與對局頁共用渲染）+ 開局階段提示橫幅
- 假先方視角：放置游標、「確認此子」按鈕、「悔最後一子」按鈕
- 假後方視角（觀看階段）：唯讀棋盤 + 「等待對手開局…」
- 假後方選擇階段：三個選項按鈕，各附簡短說明：
  - 執黑 / 執白 / 放置第四五子（再由對手選色）

## 互動行為
- 假先方放置 → 確認 → 落子動畫 + 同步雙方（OpeningStonePlaced）
- 假先方「悔最後一子」→ 移除最後放置子（僅限最後一子，需求 #31）
- 假後方點選一個選項 → Swap2ChoiceMade → 顏色定案 → 進入正式對局
- 權限控制：非當前操作方的互動元件禁用
