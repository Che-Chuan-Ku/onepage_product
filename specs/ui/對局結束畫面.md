# 對局結束畫面

來源：需求 #12（勝負高亮與結束畫面）

## 描述
對局結束時的覆蓋畫面。高亮連五位置（動畫），顯示勝者 / 和局、落子數、耗時，並提供再戰按鈕。

## 佈局
- 連五位置高亮動畫（疊在棋盤上）
- 結果橫幅：勝者暱稱 / 「和局」（含雙方同時斷線判和）
- 統計：落子數、對局耗時
- 「再戰」按鈕（本地：保留名稱重置；線上註冊玩家：發起 rematch）
- 訪客線上局結束：不顯示「再戰」，改顯示「重新輸入暱稱進新局」+「強烈建議註冊」提示（Q4）

## 互動行為
- 收到 WinConditionMet / GameDraw / GameEnded → 顯示本畫面
- 點「再戰」→ 本地重置（需求 #14）或線上重新開局
- 訪客線上局：點「重新進新局」→ 導回暱稱輸入；提示文案引導註冊（Q4）
- 觀戰者：僅顯示結果，無再戰／重新進局操作
