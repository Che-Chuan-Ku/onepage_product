# PVE 職業選擇頁

來源：PVE 增量 FR-B1（documents/PVE-挑戰模式-增量需求.md）

## 描述
建立新 PVE Run 前的職業選擇畫面。單人流程，無需等待對手；選定職業後立即建立 Run 並進入第 1 關。

## 佈局
- 兩張職業卡片：劍士（附贈技能：橫劈 HORIZONTAL_SLASH）、弓箭手（附贈技能：精準狙擊 PRECISION_SNIPE），
  各附簡短技能組說明（劍士：橫劈/縱劈/大絕天地反轉；弓箭手：精準狙擊/散射/大絕開拓之星）
- 說明文字：本關手數預算 30、Boss HP 100（第1關）、棋盤 11×11、無場地效果（PLAIN）
- 若使用者已有進行中 Run：不顯示本頁，直接導向續玩（見模式選擇首頁互動行為）
- 「開始挑戰」按鈕（未選職業時停用）

## 互動行為
- 點選職業卡片 → 高亮標示選擇
- 點「開始挑戰」→ 呼叫建立 Run（POST /pve/runs），成功後導向 PVE 棋盤關卡頁
- 若當下已存在進行中 Run（422）→ 顯示錯誤提示並導向續玩該 Run（FR-C8 一帳號僅 1 個進行中 Run）
