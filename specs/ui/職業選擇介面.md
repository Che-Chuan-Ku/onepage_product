# 職業選擇介面（真劍勝負模式）

來源：需求 #35（職業選擇與鎖定）

## 描述
真劍勝負房間內、Ready 前的職業選擇區塊（嵌於房間頁）。玩家可自選劍士或弓箭手，可與對手同職業；選擇階段看不到對手選擇；Ready 即鎖定，對局開始時雙方職業同時揭曉。

## 佈局
- 兩張職業卡片：劍士（技能：橫劈/縱劈/大絕天地反轉）、弓箭手（技能：精準狙擊/散射/大絕開拓之星），各附簡短技能圖示與說明
- 目前選擇高亮標示；未選擇時「Ready」按鈕停用
- 對手選擇區顯示「? 選擇中」（不揭露內容），直到職業揭曉

## 互動行為
- 點選職業卡片 → 更新自己的選擇（ClassSelected），Ready 前可重複更改
- 標記 Ready → 鎖定職業，不可再變更
- 雙方皆 Ready、對局進入 PLAYING 狀態 → 觸發「職業揭曉」動畫（ClassesRevealed），雙方職業卡片同時翻面顯示
