# PVE 結算畫面

來源：PVE 增量 FR-B7（關卡結算）、FR-C7（Run 結算）（documents/PVE-挑戰模式-增量需求.md）

## 描述
涵蓋兩種結算情境的覆蓋畫面：（1）單關失敗時的關卡結算；（2）Run 結束（通關全8關/失敗/主動放棄）
時的 Run 結算。兩者共用版面骨架，依情境顯示不同區塊。

## 佈局
- 關卡結算（單關失敗，FR-B7）：
  - 結果橫幅：「挑戰失敗」
  - 統計：本關造成總傷害、剩餘手數（0）、已使用技能清單
  - 導向：自動接續顯示 Run 結算（因失敗即整個 Run 終止）
- Run 結算（FR-C7）：
  - 結果橫幅：「Run 完成」（8關全通過）/「Run 失敗」（第N關失敗）/「已放棄」
  - 統計：到達關數（N/8）、全 Run 總傷害、獲得金幣、花費金幣、最終持有遺物清單、最終持有技能清單
  - 「返回首頁」按鈕（結束本輪 Run，可重新選擇職業建立新 Run）

## 互動行為
- 收到關卡失敗（ENCOUNTER_FAILED）→ 顯示關卡結算，接著顯示 Run 結算（LOST）
- 收到第8關通過 → 顯示 Run 結算（WON），不經過商店
- 點「放棄挑戰」確認後 → 直接顯示 Run 結算（ABANDONED）
- 點「返回首頁」→ 導回模式選擇首頁；此時已無進行中 Run，可建立新 Run（FR-C8）
