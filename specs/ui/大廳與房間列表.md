# 大廳與房間列表

來源：需求 #5（建立/加入房間、公開房間列表）、#6（快速配對）、#26（Swap2 房間標籤）、#34（真劍勝負場地選擇）

## 描述
線上連線入口頁。提供建立房間、輸入房間碼加入、瀏覽公開房間列表、快速配對。

## 佈局
- 「建立房間」按鈕（彈出設定：私人/公開、房間模式「普通 / Swap2 / 真劍勝負」三選一互斥；選真劍勝負時額外顯示場地選擇「火山 / 沙灘」）
- 「輸入房間碼加入」輸入框 + 加入按鈕
- 「快速配對」按鈕
- 公開房間列表（每列顯示：房間碼、房主、對戰人數/2、觀戰人數、模式標籤「普通 / Swap2 / 真劍勝負(場地圖示)」）

## 互動行為
- 建立房間成功 → 進入房間頁，顯示房間碼供分享
- 建立房間彈窗：勾選「真劍勝負」時強制要求選擇場地，且與「Swap2 模式」互斥（同時勾選時提示二擇一，需求 #34 Q9）
- 加入房間：碼不存在 → Toast「房間不存在」；對戰席滿 → 以觀戰者身份進入（不再阻擋）
- 快速配對：無對手 → 顯示「配對中…」等待動畫；逾 60 秒 → Toast「排隊過久請重新開始配對」並退出佇列（Q6）；配對成功 → 進入房間 / 直接開局
- Swap2 房間以明顯標籤與普通房間區分（需求 #26）；真劍勝負房間標籤額外顯示場地圖示（火山🌋 / 沙灘🏖️）
