# 訪客玩家 (GuestPlayer)

## 描述
未註冊、輸入暱稱即可遊玩的人類使用者，目的為降低進入門檻（需求 #2）。本地模式全功能支援；線上模式僅限「單場」遊玩（不累積跨場戰績）。以臨時 Player 實體 + localStorage 表示，不持久化到資料庫帳號。

## 類別
外部使用者（透過 Web UI 主動操作系統）

## 關鍵屬性
- guestId：臨時識別（前端 localStorage 產生）
- nickname：玩家自輸入暱稱
- 無 email / 無密碼 / 無持久戰績

## 可執行行為（來源：需求明細 CSV）
- 輸入暱稱進入遊戲（#2）
- 選擇遊戲模式（#4）
- 本地雙人對戰（全功能，#13 #14 #25）
- 線上連線（僅限單場，#2）
- 線上即時落子（#9）
- 觀戰他人線上對局（唯讀，Q5）
- Swap2 開局放置與選擇（假先方）（#28 #29）
- 建立/加入真劍勝負房間並選擇職業（線上單場限定，同註冊玩家規則）（#34 #35 #36）

## 限制（來源：需求 #2、Q4、Q5；PVE增量文件 §4.2）
- 線上模式僅限單場，不累積戰績、不進排行榜
- 線上單場結束後不可直接再戰；須重新輸入暱稱進新局，結束畫面顯示「強烈建議註冊」提示（Q4）
- 以觀戰者加入房間時為唯讀：不可落子、不參與 Ready（Q5）
- **不可遊玩 PVE 挑戰模式**：PVE 僅限已登入玩家（documents/PVE-挑戰模式-增量需求.md §4.2），
  訪客玩家嘗試建立 Run 應被拒絕並導向註冊/登入
