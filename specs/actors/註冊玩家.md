# 註冊玩家 (RegisteredPlayer)

## 描述
透過 Email/Username + 密碼註冊並登入的人類使用者。登入後系統發放 JWT 作為後續操作的身份憑證。可使用本地雙人與線上連線兩種模式，且其對戰結果會被記入個人戰績與排行榜。

## 類別
外部使用者（透過 Web UI 主動操作系統）

## 關鍵屬性
- userId：系統內唯一識別（string）
- username：登入帳號 / 顯示暱稱
- email：註冊信箱
- passwordHash：密碼雜湊（不以明文儲存）
- 戰績：勝場、敗場、勝率、最近對戰紀錄（來源需求 #3）

## 可執行行為（來源：需求明細 CSV）
- 註冊帳號（#1）
- 登入並取得 JWT（#1）
- 查看個人戰績與排行榜（#3）
- 選擇遊戲模式（本地雙人 / 線上連線）（#4）
- 建立 / 加入房間（含私人房間碼、公開房間列表）（#5）
- 對戰席滿時以觀戰者身份加入觀戰（唯讀，Q5）
- 快速配對（#6）
- 房間內標記 Ready、聊天（#7）
- 線上即時落子（#9）
- 本地雙人輪流落子（#13）
- 本地再戰 / 重置（#14）
- Swap2 開局放置與選擇（假先方）（#28 #29）
- 開局悔最後一子（#31）
- 查看遊戲歷史與回放（#17 #32）
- 建立真劍勝負房間並指定場地（火山/沙灘）（#34）
- 進房後 Ready 前選擇職業（劍士/弓箭手，可同職業）（#35）
- 真劍勝負對局中每回合選擇動作：純落子／附掛一般技能／施放大絕（#36 #37）
- 使用劍士技能組（橫劈/縱劈/大絕天地反轉）或弓箭手技能組（精準狙擊/散射/大絕開拓之星）（#42 #43）
- 真劍勝負對局斷線後重連，恢復技能已用與場地狀態（#46）
- 選擇職業（劍士/弓箭手）建立 PVE 挑戰 Run（單人，僅限已登入玩家，PVE增量FR-B1）
- PVE 關卡內落子並結算連線傷害，擊破 Boss HP 通關（PVE增量FR-B2 FR-B3 FR-B4）
- PVE 關卡內於任兩手之間使用技能（獨立行動、消耗型，每間隔至多1個，PVE增量FR-B5）
- PVE 斷線或重新整理後從最後一手續玩（PVE增量FR-B6）
- 通過 PVE 關卡後於商店購買遺物/技能、重抽或跳過，構築 8 關 Run（PVE增量FR-C3 FR-C4）
- 主動放棄 PVE Run（視同失敗）或於 Run 結束查看結算（到達關數/總傷害/持有遺物技能，PVE增量FR-C7）

排行榜規則（Q2 已定）：主排序鍵勝場數 DESC、並列以勝率 DESC 為次鍵；上榜門檻為累計對局數（勝+敗）達 10 場。

PVE 挑戰模式為單人模式，與本地雙人/線上連線的房間、對戰、觀戰機制完全獨立（見
documents/PVE-挑戰模式-增量需求.md）；同一帳號同時至多 1 個進行中的 Run（PVE增量FR-C8）。
